# 🦸‍♂️ Marvel vs DC - Comparador de Héroes 🦸‍♀️

¡Bienvenido al proyecto **Marvel vs DC**! 🌟 En esta web podrás ver a los héroes de Marvel y DC, compararlos, y saber quién ganaría en una batalla épica. ⚔️

## 🚀 Descripción

Este proyecto te permite explorar a los héroes más poderosos de **Marvel** y **DC**, cargando sus datos desde una API. Puedes ver su **biografía**, **fuerza de ataque**, **resistencia**, e imágenes. Y, como parte de la diversión, ¡puedes compararlos y ver quién ganaría en una pelea! 💥

## 💻 Funcionalidades

- **Ver héroes**: Carga y muestra héroes de **Marvel** o **DC** con un solo clic. 🦸‍♂️🦸‍♀️
- **Paginación**: Si hay muchos héroes, puedes navegar entre páginas para ver más. 📄➡️
- **Comparar héroes**: Con el botón "Comparar Héroes", elige un héroe aleatorio de **Marvel** y uno de **DC** y compáralos en una batalla épica. 🔥⚡
- **Detalles de los héroes**: Cada héroe tiene detalles como su **nombre**, **aparición**, **biografía**, **resistencia**, **fuerza-ataque** y su **imagen**. 📝📸

## 🌍 ¿Cómo funciona?

1. **Cargar los héroes**:
   - Cuando presionas el botón **Cargar Marvel** o **Cargar DC**, la página realiza una solicitud a la API para obtener los datos de los héroes y los muestra en pantalla. 🌐
   - Los héroes se muestran con paginación, 3 héroes por página. Puedes navegar entre las páginas usando los botones de paginación. 🔢

2. **Comparación de héroes**:
   - Al presionar el botón **Comparar Héroes**, se seleccionan un héroe de **Marvel** y un héroe de **DC** al azar.
   - Se compara su **Fuerza-Ataque** y **Resistencia**. El héroe con la mayor puntuación es el ganador. Si ambos tienen la misma puntuación, el ganador se elige de manera aleatoria. 🎲🏆

## 🎨 Estilo

El diseño tiene un estilo limpio y moderno, utilizando tonos de **azul** y **blanco** para una sensación fresca y vibrante. Los héroes se muestran con sus imágenes y detalles de manera visualmente atractiva. ✨

## 🛠️ Tecnologías

- **HTML**: Estructura de la página web.
- **CSS**: Estilos y diseño visual.
- **JavaScript**: Lógica para cargar los héroes, hacer comparaciones y manejar la paginación.
